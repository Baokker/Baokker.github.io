我推荐安装的MacOS软件（2026年版）

前言

转眼距离我第一篇写MacBook的博客已经过去近4年了。手里这台老Mac也陪我度过了许多风风雨雨。我也可以非常自信地说，尽管当年买这台Mac时咬咬牙出了不少心血，但它带给我的收益已经远远大于获得它所付出的成本。

回头再看当年写的那篇Mac体验一月指南，其中的基础操作固然仍然可以使用，但是里面的很多软件，甚至我自己也没有在使用了。恰好最近有一些空的时间，想写一写今年自己主要在用的软件，更新一下最新版本的内容。网上关于macOS教学的博主已经发了够多内容了，所以我只写一点自己比较有心得的地方。

效率工具

Raycast

官网下载

事实上，我已经很久没有用过macOS自带的聚焦搜索，一直用的是Raycast。关于这个软件，我之前写过一篇Raycast：Alfred和Magnet的免费替代。总的来说，我认为它把聚焦搜索的功能囊括并优化，同时还引入了更多功能。一个软件相当于Alfred加聚焦搜索加Magnet加Caffeinate，所以我很喜欢。

我使用它的场景包括但不限于打开软件、查找文件、剪贴板和分屏。剪贴板我设置成了双击Command键打开，非常方便。分屏需要自己设置一下快捷键，我设置的是下面这几个。

  1. Control + Option + 左键，左半屏
  2. Control + Option + 右键，右半屏
  3. Control + Option + M，合适大小，刚好可以展示台前调度剩下四个窗口的大小
  4. Control + Option + Enter，全屏

另外它还有很多插件可以配置。我主要配置了Caffeinate插件，因为今年有非常多需要让电脑一直awake去跑Agent的情况。为了避免电脑休眠，可以通过它来配置，并且可以灵活自定义电脑不休眠的时间。

Mos

官网下载

一个非常非常轻量级的软件，用途只有一个，就是优化我几乎不曾使用的鼠标使用体验。众所周知，macOS上的鼠标滚轮方向和Windows上相反，这个体验实在过于反人类，所以我会安装一下Mos，把这个方向reverse一下。同时它应该也有一定的鼠标体验优化。虽然我平时几乎真的不用鼠标，只用触控板，但我还是装了这么个软件，以防万一。在两套操作系统上维持两个截然不同的习惯，实在太折磨人了。之前也写过一篇介绍，Mac的鼠标伴侣Mos。

Tencent Lemon

官网下载

腾讯出品的一个非常不错的免费清理垃圾的软件。除了常规的垃圾扫描之外，还有大文件检索、磁盘分析等功能，我都觉得挺实用的。

UU远程

官网下载

最近安装了一个非常好用的远程控制软件。需求场景其实非常简单，最近有非常多需要Agent长时间去跑的任务，但我又不可能一直蹲在电脑前，还要去过自己的生活。所以只需要挂一个UU远程，并且设置为锁屏时可以唤醒电脑，就可以在外面舒适地玩耍。等到玩不动了、休息的时候，顺带看一眼手机，看看Agent的活跑得怎么样了，有没有什么问题。这样我在外面玩耍，它在家里干活，只可惜我的从前慢，终究还是回不来了。

豆包输入法

官网下载

记得之前还写过一篇博客，介绍自己为什么还是喜欢在macOS上使用原装输入法。然而在豆包输入法出来以后，我非常不带任何犹豫地把输入法从原装切换到了豆包输入法。原因很简单，现在语音输入实在是太方便、太快捷了，而我说话的速度就是比打字的速度要快很多。尤其是现在给Agent派活的时候，需要介绍非常多的上下文，来让它确保理解项目需求和目标，这个过程如果通过打字来敲的话非常费劲。用语音输入法输入的文本，已经足够让AI理解我的意图。

而且现在豆包语音输入法也推出了智能整理功能，相当于先用火山引擎把语音转成文本，然后再用一层模型做简单的润色和排版，这样出来的文本更加书面化。事实上，我这篇博客的初稿就是通过语音输入完成的。

开发与终端

VS Code / Cursor

VS Code官网，Cursor官网

这个没啥好说的，本来就是写代码的人手一个的软件。虽然现在其实用Claude或者GPT也可以访问文件目录，但总体的预览效果还是没有这种IDE来得方便和快捷。我个人会更喜欢Cursor，因为平常会有比较多的Markdown文件，而Cursor的Markdown preview做得很好，可以在单个页面里面做到所见即所得。VS Code如果想要编辑Markdown的话，必须左右分屏，看着不是很舒服。

Warp

官网下载

之前也写过一篇博客，Warp：现代的command line tool。它是终端命令行的神，能把丑丑的终端做得这么赏心悦目，确实很厉害。别的不说，光是以前敲命令时，经常要为了改前面几个字符而笨拙地一直按左键，让光标移到前面去，然后再移到最后面。而在Warp里面，只需要用鼠标就可以像图形化界面一样控制命令行，这个体验就已经秒杀了太多软件。

Termius

官网下载

其实这个软件我最近不怎么用了，但我认为它用来连接一些固定的SSH服务器，配置起来还挺方便的。

OrbStack

官网下载

一个比Docker Desktop更加轻量级的容器管理软件，同时支持Linux虚拟机和Docker管理。有人会问，为什么你不装原装的Docker Desktop呢？原装的当然是最完善的，但是它占的空间实在太大了，而我的空间有点有限。

AI Agent

Claude / Codex / CC Switch

Claude下载，Codex官网，CC Switch项目地址

AI Agent自然是我在2026年推荐的macOS软件里的一大重点。前段时间跟朋友聊起的时候数了一下，发现我的电脑上已经装了七八个Agent，包括但不限于Claude、Codex、OpenCode、Deepseek Harness、WorkBuddy、Hermes、豆包、OpenClaw，正所谓群贤毕至，少长咸集，齐齐哈尔。

如果一定要让我推荐必须装的Agent，那我依然还是推荐本小节提到的Claude、Codex和CC Switch。Codex主要是量大管饱，即使不是最聪明的这一档，也已经足够好用，并且性价比足够高。Claude我真的是非常心水。最近5.5的表现非常好，不仅思考非常积极，而且具有很高的思辨性，同时具有一定的对抗性。不像GPT，我在聊天的时候，它更多是顺从我的命令，而不会反过来问我这些事情的可行性。很多时候我感觉更像是我在让GPT干活，而Claude是在指挥我干活。GPT是我的实习生，而Claude更像是我的MT，我们两个人在共同讨论目标的实现。

所以就像我之前写的一篇博客里一样，现在我使用Agent会更加根据任务本身的难度和时效性来选择，毕竟不同Agent的价格和速度都不一样。最近我的Workflow是这样的。

第一类是特别复杂的项目，比如我的毕业设计，或者需要说人话一点的事情，比如求职时的面试复盘和策略分析，以及我自己的个人事务和自我复盘，这些内容我都和Claude进行。毕业设计里的具体执行，则让Claude写提示词，交给更便宜的Agent，比如GPT来执行。

第二类是比较简单的项目，我会直接让GPT去执行，甚至可以让Deepseek Harness来做。对于我有明确预期的方法和结果的项目，只需要一个能力足够且够便宜的Agent就可以。但对于复杂的项目来说，让不够聪明的Agent去跑，反而会带来更大的成本，这就好像考试做题一样。面对同样的难题，学霸只需要两到三步就可以想到正确的解法，很快就能做出来。而脑子不那么聪明的学生，则需要在脑子里盘旋很多步，才能找到一个相对正确的解法。这其中带来的思维成本和token消耗，其实反而比学霸高非常多（点名Deepseek Flash啊）（蓝色大肥鱼不要哭）。

顺带一提，本文也是用我的Claude Pro完成的，意外地发现20刀的用量确实够我用，因为我只跟它进行一些宏观架构上的讨论和结果review，具体的事情再让其他Agent去干。

WorkBuddy / Deepseek Harness

WorkBuddy官网，DeepSeek Harness官网

理由同上，2026年为Agent付费是件很值得的事情。如果预算有限，或者不方便使用国外模型的话，WorkBuddy或者Deepseek Harness我觉得都是不错的选择（再见了豆包）。

阅读与影音

Skim

官网下载

一个非常轻量级的PDF阅读和编辑软件，之前我也写过一篇博客，Mac上的一款优质PDF阅读软件推荐，Skim。

剪映

官网下载

犹记得高中的时候，我还在认真学习和使用PR，同时百度网盘里面还存了各种下载过来的PR资源预设、字幕预设等等。但现在剪映把这一切都简化了太多。做简单的视频剪辑真的非常够了，比iMovie更加本土化，有更多适合短视频的模板特效，也有一定的美颜美体功能，同时足够简单易上手。不像PR那么看上去高高在上、令人畏惧，这就够了。

IINA

官网下载

非常好用、非常轻量级的视频播放软件，感觉类似于Windows上的PotPlayer吧。

不需要安装的系统自带软件

日历、备忘录、提醒事项、iPhone镜像、手记，这些都是系统自带的。关于它们，我其实已经写了很多博客来介绍自己的一些尝试和探索，比如笔记的笔记，我如何整理笔记、我如何使用苹果的提醒事项管理我的生活、苹果的设计哲学，过犹不及（手记），以及苹果邮件APP使用教程。

因为我自己是苹果生态的用户，不得不说，这些软件的生态联动帮助我提升了非常多的效率。比如在Mac上设好提醒事项，然后在手表和手机上都能同时提醒；灵感迸发时，在手机上写下备忘录，然后回到电脑上再把它完善、编辑；在日历上记录我匆匆忙忙的秋招，等等。
