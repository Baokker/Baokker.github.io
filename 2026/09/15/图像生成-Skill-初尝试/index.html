图像生成 Skill 初尝试

最近刷到了很多图像二次创作的 Skill。这几天盘点了一下，也试用了一下，各有各的风格，并且确实很有意思。这里记录三个我自己比较喜欢的。

photo-abstract-editorial

这个 Skill 的特点是把一张照片分成两部分，一部分保留原始的摄影图片，另一部分加上一个抽象的画板区域，同时在里面加上一些英文标题。看着挺有意思，把之前约拍的照片拿来放进去，效果也还不错。

DS：它的逻辑其实挺克制的。它不会重画你的照片，也不做滤镜或者风格迁移，上半部分的照片就是原本的样子，下半部分的抽象面板则是从照片里提炼出来的空间关系、构图节奏和色彩关系。作者的说法是，抽象面板里的每一个元素，都应该能追溯到原照片里真实存在的空间、色彩或者结构。所以它出来的东西不会太飞，有一种把照片里说不出来的那部分，翻译成图形的感觉。

并且我觉得这个 Skill 比较好的一点是，它除了可以在 Codex 里使用之外，还提供了一个可以直接当提示词用的版本。所以理论上说，你可以直接复制这段提示词（references/photo-abstract-editorial-prompt.zh-CN.md），然后发给其他任意支持图片生成的 AI，比如豆包或者 Gemini，或者是 GPT 网页版，而不是仅仅局限在 Codex 里，使用成本也会比较低。

scenes-gathered-zine-v1-3

这也是我经常在 dy 上刷到的 skill，很喜欢的一点是，它生成的图片会有一种现实和虚拟交织的感觉。

DS：它其实是一整个系列，叫「拾景纸刊」，作者是 Zeejay0，主张是「把普通画面，变成值得停留的一页」。里面有两个互补的 skill：一个叫实景拼贴，会保留原照片的现场感，让摄影、抽象插画和手撕纸的边缘一起构图；另一个叫影像蒸馏，就完全不留原照片了，只从照片里提取情绪和张力，重新做一张独立的插画。我用的这个是前一个，所以成品里才会既有照片的真实，又有插画的想象。

它给我的感觉是，它不太像在给照片套模板，而像先「读」一遍你的照片，找到主体、空间、色彩，还有那些没有说完的情绪，再决定怎么把这一页做出来。

https://zeejayzine.com/

这个博主还是懂变现的，已经把他的这一套 Skill 包装成了一个可以付费进行图片生成的网站。一条龙，直接用 GPT Image 配合 Skill 生成图片，非常有思路。果然现在就需要这种既懂产品又会 Coding 的人。

简单注册一个账号，把我的香港随拍丢给它。

photo-relic-editorial

这个 skill 的效果是把图片分为上下两栏：上栏是真实图片，下栏是剪纸版的抽象，也很有意思。

DS：和第一个不同的是，它的下半部分更像一幅版画。作者管它叫「纸上留影」，说是要把照片压缩成一张安静的纸上记忆。它适合那些轮廓清楚、光影和倒影比较强的照片，比如古建筑、地标、天际线、桥和塔。作者自己有一组「纸上北京」的例子，会配上四个字的中文小标题，像「天光有序」「水照宫墙」这种，味道很足。我觉得它很适合旅行时拍的城市照片。

用雾蒙蒙的维多利亚港作为素材喂给WorkBuddy尝试了一下。

使用方法

1️⃣ 有任意可以生成图片的 Agent（Codex 最佳，豆包和 WorkBuddy 我都试了一下，也可以跑通，但是效果没有那么好，个人感觉 CodeX >> WorkBuddy > 豆包，可能豆包确实更适合生成奶蛙吧）

2️⃣ 让 Agent 来安装 Skill

帮我安装这些 skill：

  • https://github.com/ZzzLc0405/photo-abstract-editorial
  • https://github.com/Zeejay0/gathered-scenes-zine-skill
  • https://github.com/wnby/photo-relic-editorial

3️⃣ 上传图片，让 AI 使用特定的 Skill 生成图片，可以使用/来引出技能名，比如
